Registration

Registration is organized at the team level. Each team should complete the Google Form once.

Registration Rule

  • Each team should register only once, up to 10 members.
  • Each registration is valid for either a single track or both tracks.
  • Each person can only be registered in one team.

Required Information

Field Requirement
Team ID Required per team, will be used as the reference for submission.
Member Name Required for each team member
Member Email Required for each team member
